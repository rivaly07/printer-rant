A deterministic Python program that writes a concise rant about a printer's misleading “Ready” light and cryptic paper error.

## Run it

```sh
python3 main.py
```

The program writes UTF-8 text to `/output/entry.txt`. Set `MAKEFUN_OUTPUT_DIR` to use a different output directory during local testing.
